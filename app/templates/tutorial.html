🔒 Configuración Inicial del Sistema

Sigue estos pasos para autorizar el acceso seguro desde tu dispositivo.

Paso 1: Descargar el Certificado

Presiona el botón de abajo para guardar el archivo de seguridad en tu dispositivo.

⬇️ Descargar Certificado

Paso 2: Instalar en el Dispositivo

  1. Abre los Ajustes de tu teléfono.
  2. Busca Seguridad y Privacidad > Otros ajustes de seguridad.
  3. Selecciona Instalar desde el almacenamiento > Certificado de CA.
  4. Busca el archivo sistema_vita_root.crt y acepta la instalación.
  1. Abre el archivo descargado para guardarlo en tu Perfil.
  2. Abre Ajustes > Perfil descargado e instálalo.
  3. Ve a Ajustes > General > Información > Ajustes de confianza de los certificados.
  4. Activa el interruptor completo para el certificado de Sistema Vita.

Paso 3: ¡Listo para trabajar!

Una vez instalado el certificado, haz clic abajo para ingresar al sistema comercial.

🚀 Entrar al Sistema Vita (PWA)
